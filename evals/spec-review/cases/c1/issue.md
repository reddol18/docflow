# 철 이벤트 목록을 나눠 받기

## 목표
진행 화면이 이벤트를 한 번에 최대 500개씩만 받고, 이어서 받을 위치를 서버가 알려 준다.

## 완료 조건
- [ ] `GET /volumes/{vol}/events`에 `limit` 쿼리 (1~500, 기본 500). 범위 밖이면 422
- [ ] 응답에 `next_after`(이번에 준 마지막 이벤트 id, 더 없으면 null)를 담는다 — 다음 요청의 `after`로 쓴다
- [ ] 시험: limit 경계(0·1·500·501)와 next_after 값

## 범위 밖
- 프런트엔드 화면 변경
